核心訂票引擎流程

核心邏輯

Booking Engine 實例自初始化、防反爬、多行程隔離防護到多路徑狀態決策之完整流程。

  • 多行程隔離防護：強制禁用 TRIP2/TRIP3 欄位，杜絕參數污染
  • 標準入口切換：正式標準入口對齊，保證 Session 上下文完整
  • 智能回饋決策：精準辨析客滿無票、成功訂票、次級驗證碼與自癒重整

驗證碼 OCR 辨識流程

神經網路

圖形驗證碼元素定位、內存直接二進制截圖、圖像預處理與深度學習字元預測。

線上退票與歷史流程

退票同步

歷史訂票紀錄查詢、跨日 24:00 繳費期限檢核、彈窗確認退票與本地資料庫同步。

  • 跨日繳費期限解析：精確處理 24:00 等特有格式，防範誤判過期
  • 雙重防呆狀態校驗：自動對齊官方已取消狀態，避免無效重複操作
  • 本地票券儲存同步：退票完成即刻更新 SQLite tickets 紀錄

單元測試與離線防護

品質保證

涵蓋純邏輯驗證、HTML 離線 Fixtures 結果解析、SQLite 資料庫隔離與全量測試流水線。

  • 純邏輯與日期解析：身分證校驗演算法 + 24:00 換日跨日精確性驗證
  • HTML 離線 Fixtures：脫離瀏覽器與網路，秒級防護官網改版與回歸錯誤
  • SQLite 隔離環境：採用獨立暫存 DB 驗證車票原子性 CRUD 與日誌佇列截斷
  • 一鍵全量/模組測試：支援 ./run_tests.sh [1|2|3]，毫秒級完成全部測試
